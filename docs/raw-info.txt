Best option: FreeBSD + bootstrap script (no VHD needed)
OPNsense is based on FreeBSD, which is a free official OS image publisher in Azure. The approach is to deploy a FreeBSD 14.1 VM and install OPNsense using the opnsense-bootstrap script. GitHub This means no VHD download, no upload, no storage account — just a free FreeBSD VM from the Marketplace and one script.
Steps:

Accept the FreeBSD free terms once per subscription (Azure CLI):

bashaz vm image terms accept --urn thefreebsdfoundation:freebsd-14_1:14_1-release-amd64-gen2-zfs:14.1.0 -o none

Create a VM from the FreeBSD 14.1 Marketplace image (free, no license fee)
SSH in and run the OPNsense bootstrap:

bashfetch https://raw.githubusercontent.com/opnsense/update/master/src/bootstrap/opnsense-bootstrap.sh
sh ./opnsense-bootstrap.sh

Reboot → OPNsense is installed, access via https://<public-ip>

There is an existing GitHub template at github.com/dmauser/opnazure that automates this entire deployment including VNet, two NICs, NSG rules, and optionally Active-Active HA with load balancers. GitHub You can deploy it with one click from the repo's README.

If you still want the VHD route
A community GitHub repo at github.com/maurice-w/opnsense-vm-images provides pre-built OPNsense VHDX images for Hyper-V (amd64), which are the closest format to what Azure needs. GitHub You'd download the .vhdx, convert to .vhd (fixed size), upload to Azure Blob Storage, create a managed disk, then create a VM from it. This is more work with no real benefit over the bootstrap method above.
